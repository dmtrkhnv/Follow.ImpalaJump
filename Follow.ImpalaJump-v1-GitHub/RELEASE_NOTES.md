# Follow.ImpalaJump v1

First public Windows release.

## Included

- Live follower count for public Instagram accounts
- `@username | session change` centered below the main number
- Refresh intervals from 1 second to 10 minutes
- START / STOP controls
- Automatic milestone progression
- Manual milestone target with automatic return to the next automatic target after celebration
- Follower-change sound
- Fireworks/fanfare milestone sound
- Dark and Light modes
- Fullscreen mode
- Direct Instagram profile link
- No Instagram login, password, or API key required
- Hidden local browser automation
- Single-instance Windows application
- Automatic shutdown after the dashboard is closed

## Download

Download `Follow.ImpalaJump-Windows.zip`, extract it, and run `Follow.ImpalaJump.exe`.

Windows may show a SmartScreen warning because the executable is not code-signed yet.
