# Publishing Follow.ImpalaJump v1

1. Push this repository to GitHub.
2. Open the repository on GitHub.
3. Open **Actions**.
4. Select **Build and publish Windows v1**.
5. Click **Run workflow**.
6. Wait for the workflow to finish.
7. Open **Releases** and verify that release `v1` contains:
   - `Follow.ImpalaJump-Windows.zip`
8. Download the ZIP and test the EXE once before sharing the release publicly.

The workflow rebuilds the Windows EXE on GitHub and recreates the `v1` release.
